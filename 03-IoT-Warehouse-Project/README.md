# Smart and Secure Warehouse Management System Using IoT

## Project Overview

This project was completed during my Bachelor of Engineering in Electrical and Electronics Engineering at Anna University in 2021.

The objective was to develop a prototype capable of monitoring warehouse environmental conditions and identifying potential fire-related hazards using IoT technology.

The project was completed by a team of three students.

## Hardware and Technologies

- Arduino UNO
- ESP8266 NodeMCU
- LM35 temperature sensor
- DHT11 temperature and humidity sensor
- Flame sensor
- Gas sensor
- Embedded systems and IoT communication
- Regulated DC power supply

## Project Activities

The prototype integrated environmental sensors with microcontroller hardware to support warehouse monitoring and hazard detection.

The project involved hardware connections, sensor testing, power-supply arrangements and technical documentation.

## My Personal Contribution
