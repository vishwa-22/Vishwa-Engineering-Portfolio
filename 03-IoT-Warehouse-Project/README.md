# Smart and Secure Warehouse Management System Using IoT

## Project Overview

This academic project was completed in 2021 during my Bachelor of Engineering in Electrical and Electronics Engineering at Anna University, India.

Our three-member team developed a prototype designed to monitor warehouse environmental conditions and identify potential fire-related hazards using sensors and IoT technology.

The project provided practical experience in basic electronic hardware connections, sensor testing, embedded systems and prototype development.

## Hardware and Technologies

- Arduino UNO
- ESP8266 NodeMCU
- LM35 temperature sensor
- DHT11 temperature and humidity sensor
- Flame sensor
- Gas sensor
- LCD display and buzzer
- Regulated DC power supply
- IoT and embedded systems fundamentals

## Project Activities

The prototype integrated environmental sensors with microcontroller hardware to monitor warehouse conditions and identify abnormal readings.

The system used threshold-based alerts, with information displayed on an LCD screen and audible warnings generated through a buzzer.

The team worked on hardware connections, sensor integration, power-supply arrangements, prototype testing and technical documentation.
