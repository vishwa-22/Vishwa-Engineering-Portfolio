# Revit MEP – HVAC Layout and Drafting

## Project Overview

This project presents practical HVAC drafting work completed during MEP Designing and Drafting training at CADPOINT in 2020–2021.

The main drawing is titled **Mezzanine Ground Floor AC Layout**, prepared using Autodesk Revit MEP.

## Software

- Autodesk Revit MEP 2018
- Autodesk AutoCAD 2018 (training exposure)

## Project Activities

- Prepared an HVAC layout using supplied reference drawings and specifications.
- Followed the provided duct routing and dimensions.
- Arranged fan coil units, supply and return diffusers, and extract grilles.
- Incorporated airflow information and mechanical services annotations.
- Prepared the final HVAC drawing using Revit MEP.

## Technical Details

The drawing includes:

- Main duct pressure-loss criterion: 0.57 Pa/m
- Low-level branch duct criterion: 0.4 Pa/m
- Branch duct design velocity: 2.5 m/s
- Airflow labels including 236 L/s and 206 L/s
- Duct dimensions including 275 × 356 mm and 325 × 356 mm

## My Contribution

I prepared the HVAC layout using the reference information supplied during training.

I did not independently calculate or select the original duct sizes. This was an academic training exercise, not a commercial engineering project.
