# SolidWorks – Gear Train Modelling

## Project Overview

This project presents SolidWorks gear train modelling work completed as part of the EG7010 engineering coursework during my MSc studies at the University of Leicester.

The assignment provided practical exposure to mechanical modelling, gear arrangements and engineering design principles.

## Software and Tools

- SOLIDWORKS
- 3D CAD modelling
- Mechanical component modelling
- Gear train arrangement and visualisation
- Engineering design documentation

## Project Activities

- Worked on an academic gear train modelling assignment.
- Explored the arrangement and interaction of mechanical gears.
- Applied mechanical modelling concepts using SolidWorks.
- Documented the assignment work and technical observations.

## Skills Demonstrated

- Familiarity with 3D CAD software
- Understanding of basic gear train principles
- Mechanical design visualisation
- Technical documentation
